# Frontend development guidelines

These are approved initial conventions with actual homepage examples. Editor, persistence and
generated-content behavior remain prospective. Product copy and root product docs are Chinese.

## Pre-Development Checklist
- Read [structure](./directory-structure.md) and [components](./component-guidelines.md).
- Read [hooks](./hook-guidelines.md), [state](./state-management.md) and [types](./type-safety.md).
- Confirm pages P01-P11 and requirement IDs before editing behavior.
- For service state, read [the shared capability contract](../backend/capabilities-contract.md).
- For project-page generation and source edits, read [the generation contract](../backend/project-generation-contract.md).
- For historical previews, restore and downloads, read [the version contract](../backend/version-history-contract.md).

## Quality Check
Follow [quality](./quality-guidelines.md). Verify API boundaries, accessibility, real status and responsiveness.
Add real file examples as code lands; prospective conventions are explicitly labeled.
