# 项目页开放生成与网页/游戏修改

用户已授权开放上一轮指出的能力：游戏生成、基于当前网页/游戏版本的自然语言修改、
以及从项目详情直接启动幻灯片和视频。覆盖 R02/R05/R06/R12/R13/R14/R26。

验收：
- WEB/GAME/SLIDES/VIDEO 项目页均有真实可执行的生成入口，不再统一显示尚未开放。
- GAME 调用真实文本模型产生完整可交互单文件游戏，不以模板充当生成结果。
- WEB/GAME 通过修改说明和基础版本提交修改；模型读取当前源码，成功写新版本，
  失败保留旧版。基础版本过期时拒绝，不能静默覆盖。
- 幻灯片沿用本地排版引擎并明确说明；视频支持项目页选择已有模型和规格。
- 同项目同时提交不会启动重复执行；取消与最终版本提交必须原子互斥。
- 修改记录、基础版本、模型结果和失败信息可在刷新后读取。
- 预算预留串行化；已尝试付费请求的失败/取消不释放未知费用占用。
- 前端构建、真实 MySQL 集成测试（模型桩）、浏览器入口与交互检查通过。

此任务不是完整 v3 交付：不扩展独立八角色智能体、应用数据库、公开发布、
源码编辑器、PPTX/PDF 导出或媒体逐帧编辑。真实模型账户能否成功调用单独注明。
不因检查而产生未计费预留的模型调用，不改密钥，不提交 Git。
