# 历史版本、恢复和源码下载

继续已授权 v3 计划，交付 R07/T07、R11/T11 的源码导出部分，以及 R06/R28。
当前项目只显示当前快照；新增历史列表、历史预览、恢复和 WEB/GAME 源码 ZIP。

- 四类项目均可分页查看版本号、来源、摘要、创建时间和当前版本标记。
- 查看历史版本不改变当前版本；预览绑定用户选择的版本。
- 恢复要求确认，保留全部历史并新建 RESTORE 版本；记录父版本与恢复来源。
- 恢复校验当前版本、项目归属、活跃任务；重复请求幂等，冲突显式反馈。
- 源码下载仅 WEB/GAME，按选定版本导出真实文件；不调用模型。
- 刷新后历史和恢复结果仍存在；桌面和手机可用，有加载/空态/失败反馈。
- 数据库集成验证隔离、过期基线、并发重复提交、忙碌项目、文件完整性。

此任务不包含源码编辑草稿、公开发布、应用数据或模型服务开通。
恢复不会回滚业务数据、修改公开版或再次调用模型。无 Git 提交。
