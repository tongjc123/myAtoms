# S1 网页生成：从需求到可预览的单文件站点

## 背景

项目详情页此前只有一行「开始生成（尚未开放）」。幻灯片走了本地排版引擎，视频走了方舟视频任务，唯独网页没有生成路径，只能克隆模板。用户希望「真实生成内容」，而不是模板拼装或假结果。

## 目标

- 项目详情页对 WEB 类型开放「开始生成网页」，发起后跳到对话页实时展示过程。
- 生成走真实模型：两轮 Volcano Ark chat 调用（结构规划 → 页面编写），不用本地模板冒充模型产物。
- 产物是单个 `index.html`（内联样式与脚本），写入不可变 GENERATED 版本，预览与在线打开一致。
- 入库前做真实性校验：必须是完整 HTML 文档、不含任何外部资源引用、体积在限制内；不满足则拒绝入库并说明原因。
- 模型未开通 / 未配置 / 鉴权失败 / 限流 / 超时，全部如实呈现具体错误码与文案，不产生占位页面。

## 非目标

- 多轮对话式修改、结构化文件操作（多文件工程）、构建与浏览器冒烟。
- GAME 类型生成（仍为未开放）。
- 前端不做「演示模式」或假数据开关。

## 验收

- `POST /api/projects/{id}/runs` 对 WEB 项目返回 202，run 的 engine 为 `volcengine-ark-chat/1.0`。
- 成功路径：run_events 依次给出 5 个步骤（需求解析/页面结构/页面编写/页面校验/版本入库）+ WEB artifact；项目 currentVersion 为 GENERATED；预览会话可取到 `index.html`（text/html，CSP 生效）。
- 失败路径：模型返回外链页面 → `PROVIDER_OUTPUT_REJECTED`；模型未开通 → `PROVIDER_MODEL_NOT_ACTIVATED`，`status` 事件带 code 与中文原因。
- 对话页显示步骤、失败步骤标「未完成」、产物卡展示区块数/体积/版本/用量。
- 后端 `verify` 全绿，前端 `tsc` 与 `vite build` 通过。
