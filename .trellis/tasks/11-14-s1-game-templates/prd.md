# PRD：可试玩的游戏模板与克隆

## 背景

参考 Atoms 的「游戏示例」：画廊展示可玩模板，点开即可试玩，并能「基于这个游戏构建」把当前版本复制成新项目继续修改。本任务在 S1 落地这条链路，同时建立版本、文件与沙箱预览的底座，供后续真实生成复用。

## 范围

- 新增四个平台自研 GAME 模板：星海防线（射击）、霓虹疾驰（竞速）、云端跳跃（平台跳跃）、霓虹方块（解谜）。
- 模板目录公开只读：分类筛选、封面、名称、简介、作者与来源。
- 试玩弹窗：沙箱 iframe 直接运行模板入口页，右侧展示元信息，支持「在新标签页中打开」。
- 克隆：填写项目名称、确认目标工作区，服务端把模板文件快照复制成独立项目 v1。
- 项目详情页展示该版本的真实预览与版本信息。

## 非目标

- 不做模型生成；克隆产物不是生成结果，界面不得暗示已生成。
- 不导入 Atoms 或第三方仓库的模板内容。
- 本轮不提供 WEB 待办/看板模板（R20 余项后续补齐）。

## 验收

1. `GET /api/templates?type=GAME` 无会话即可返回至少四个可玩模板，含 playUrl 与 coverUrl。
2. 点击卡片能在弹窗里真正玩到游戏，键盘与触屏均可操作，有计分与重开。
3. 同一模板重复克隆（同一幂等键）只创建一个项目；不同模板克隆互不影响。
4. 克隆后的项目文件是独立副本：项目 v1 的 `kind=TEMPLATE`，`source_template_version_id` 指向所用模板版本。
5. 项目预览只通过一次性令牌访问，令牌 30 分钟过期，其他访客不能读取该项目元数据。
6. 预览响应带严格 CSP，iframe 无 `allow-same-origin`，模板路径穿越请求被拒绝。

## 风险

- 模板内容质量决定演示效果；自研游戏需保证真实可玩，不用截图或视频冒充。
- 预览令牌属于能力式链接：持有链接者可在有效期内查看该版本，需在文档中说明。
