# S1 网页模板：画廊、真实预览与克隆起点

## 背景

首页「网页」此前只有一张草稿表单，没有任何可以直接开始的素材；网页生成流水线（按需求从零生成站点）尚未接入。用户参照游戏/幻灯片的体验，希望网页也有模板。

## 目标

- 网页首页在输入框下方展示模板画廊，分类筛选（作品集/营销/活动/内容）。
- 卡片封面是真实页面的等比渲染（1280×800 iframe 缩放），悬停 140ms 后页面自行上下巡游预览。
- 点卡片进入弹窗，可切换桌面/手机视口并真实交互（筛选、价格切换、倒计时、表单校验、主题切换）。
- 「使用模板」把当前版本克隆为独立项目并跳转项目详情，预览可用。

## 非目标

- 不做网页生成流水线、可视化编辑、构建与浏览器冒烟。
- 不提供 R20 的待办工具/看板模板。

## 验收

- [x] `GET /api/templates?type=WEB` 返回 4 套模板，`playable=true`
- [x] 每张卡片封面展示真实页面内容；悬停后内容自动巡游
- [x] 弹窗桌面/手机视口均可渲染并交互；手机视口无标题重叠
- [x] 克隆产生 type=WEB、kind=TEMPLATE 的项目，预览内容与原模板逐字节一致
- [x] `api.ps1 verify` 40 项全通过（TemplateApiTest 新增 1 项覆盖 WEB 目录+克隆）
